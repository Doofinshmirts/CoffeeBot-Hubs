# CoffeeBot visual system

Cream #FAF7F2 canvas, white cards, espresso #2A1B12 text, forest #3B5340 buttons, sage #E7EEE6 badges, muted #5A5148 secondary text, #D8D1C7 borders, #A12D25 errors and #C08A3E focus accents.

Inter is used for interface text and Fraunces for the wordmark and large titles. Run scripts/fetch_fonts.py to bundle both and their OFL licenses; until available, the interface uses system sans-serif and Georgia fallbacks. No remote font requests are made by visitors.

Use 16px body text, controls of at least 48px, 16px mobile page gutters and 12-18px rounded component corners. Desktop content stops growing at 1060px. Navigation remains reachable at the bottom. Availability is always expressed in text and kilograms, not colour alone.

Illustrations are CSS shapes and an original bean SVG. Locations are labeled demonstrations. Plant illustrations indicate the reuse theme; the app does not claim raw coffee grounds are suitable for every plant or automatically establish a carbon benefit.
